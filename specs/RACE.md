# レースレポートの出力要件

`reports/` に保存するレース・スプリントレポートHTMLの表示内容を定義する。以下の6セクション・17項目は、本書の順序・番号・タイトルで生成する。1つの表示枠に1つの番号を割り当てる。

HTMLの上部ナビゲーションは6セクションへのリンク、各セクションの「グラフ一覧」は個別グラフへのリンクとする。個別リンクのアンカーは `r-01`〜`r-17`。

## 用語

- **レース全体**：レースまたはスプリントのスタートから終了までの範囲。
- **完走順位**：セッション結果に記録された各ドライバーの最終順位。
- **首位とのギャップ**：各周回の終了時点における、首位ドライバーとの累積走行時間の差。
- **前走車とのギャップ**：各周回の終了時点における、直前の順位を走行するドライバーとの累積走行時間の差。
- **タイヤ使用周回数**：FastF1の `TyreLife` に記録された、そのタイヤセットでの累積周回数。
- **車載カメラ色由来の線種**：当該シーズンの車載カメラ識別が黒のドライバーを実線、黄色のドライバーを破線で表す。

## 共通の表示要件

- 出力する図表は本書で定義する項目に限定し、タブで切り替える項目を別の図表として重複出力しない。
- PlotlyのインタラクティブFigureはHTMLへ直接埋め込み、Pythonプロセスやネット接続なしで表示・操作できるようにする。
- 静的グラフはPNGデータをHTML内に埋め込み、クリックすると画像を別タブで開く。
- テーブルを含むFigureの表示高は900 px以上、それ以外は640 px以上とする。
- テーブルを除くインタラクティブな折れ線グラフには、X軸の範囲スライダーとY軸の表示範囲を調整する2つのスライダーを表示する。
- Y軸スライダーは数値データが2点以上ある場合に表示し、操作可能範囲は全系列の最小値〜最大値に上下2%の余白を加える。初期つまみ位置はグラフの初期表示範囲に合わせる。
- R-04・R-06・R-08・R-09・R-13はHTMLへ埋め込んだPlotlyの表。ドライバー列を選択して絞り込む操作はない。

## 1. レース概要

HTMLセクション：`#race-overview`

### [R-01] 周回ごとの順位推移

- 対象：各ドライバーのレース全体の順位履歴。
- 形式：画像として埋め込む、ドライバー別の系列を持つXYプロット。X軸はラップ番号 [lap]、Y軸は順位 [rank]。1位を上に表示する。

### [R-02] 周回別のインタラクティブなラップタイム推移

- 対象：ラップタイムが記録された各ドライバーのレース全体のラップ履歴。デフォルトの表示範囲外にあるラップもデータから削除しない。
- 形式：HTMLに直接埋め込む、ドライバー別の系列を持つXYプロット。X軸はラップ番号 [lap]、Y軸はラップタイム [s]。速いタイムを上に表示する。
- 系列：各ドライバーのチームカラーと車載カメラ色由来の線種を使用する。情報を取得できない場合は灰色・実線とする。
- 表示範囲：デフォルトでは、R-07の表示範囲と「セッション最速タイム − 0.5秒〜セッション最速タイム + 14.5秒」のうち、狭い方を採用する。ユーザー操作により範囲外も確認できる。
- 操作：ドライバー系列の表示切替、ホバーによるコンパウンド・タイヤ使用周回数・スティントの確認、X・Y軸の表示範囲調整に対応する。

## 2. ギャップ分析

HTMLセクション：`#gap-analysis`

### [R-03] 首位とのギャップ推移

- 対象：各ドライバーの周回ごとの首位とのギャップ。
- 形式：HTMLに直接埋め込む、ドライバー別の系列を持つXYプロット。X軸はラップ番号 [lap]、Y軸は首位とのギャップ [s]。0秒を上に表示する。
- 初期表示範囲：0〜60秒。範囲外のデータはY軸スライダーで確認できる。
- 系列：各ドライバーのチームカラーと車載カメラ色由来の線種を使用する。
- 並び順：ドライバー系列は完走順位順とする。
- 操作：ドライバー系列の表示切替、X・Y軸の表示範囲調整、ホバーによるラップ番号とギャップの確認に対応する。

### [R-04] 首位とのギャップ一覧

- 対象：R-03と同じ。
- 形式：列をドライバー、行をラップ番号とする表。セルには首位とのギャップ [s] を表示する。首位のセルは0秒とする。
- 並び順：ドライバー列は完走順位順とする。

### [R-05] 前走車とのギャップ推移

- 対象：各ドライバーの周回ごとの前走車とのギャップ。各周回で比較相手が変わる場合がある。
- 形式：HTMLに直接埋め込む、ドライバー別の系列を持つXYプロット。X軸はラップ番号 [lap]、Y軸は前走車とのギャップ [s]。デフォルトの表示範囲は全系列の最小値から最大値までとし、Y軸スライダーの初期範囲と同じ上下2%の余白を加える。
- 系列：各ドライバーのチームカラーと車載カメラ色由来の線種を使用する。
- 並び順：ドライバー系列は完走順位順とする。
- 操作：ドライバー系列の表示切替、X・Y軸の表示範囲調整、ホバーによるラップ番号とギャップの確認に対応する。

### [R-06] 前走車とのギャップ一覧

- 対象：R-05と同じ。
- 形式：列をドライバー、行をラップ番号とする表。セルには前走車とのギャップ [s] を表示する。計算できないセルは `---` とする。
- 並び順：ドライバー列は完走順位順とする。

## 3. ラップ・ピット分析

HTMLセクション：`#lap-pit-analysis`

### [R-07] 周回別の静的なラップタイム推移

- 対象：ラップ番号・ラップタイム・記録時刻・順位が揃っている、各ドライバーのレース全体のラップ履歴。
- 形式：画像として埋め込む、ドライバー別の系列を持つXYプロット。X軸はラップ番号 [lap]、Y軸はラップタイム [s]。速いタイムを上に表示する。
- 表示範囲：上限はセッション最速タイム、下限は `IsAccurate` が真、`Deleted` が偽、かつ `TrackStatus` が通常走行を示すラップのうち最も遅いタイムを基準とする。表示範囲外の値は画像では確認できない。

### [R-08] ラップタイム一覧

- 対象：各ドライバーのレース全体のラップ履歴。ピットイン・ピットアウトを含むラップも対象とする。
- 形式：列をドライバー、行を走行順に1から数えたラップとする表。セルにはラップタイム [s] を表示し、背景色でコンパウンドを区別する。
- ピットラップ：ピットインまたはピットアウトを含む場合は、ラップタイムに加えて、ラップをピット区間とそれ以外の区間に分けた時間 [s] を表示する。

### [R-09] ピット所要時間一覧

- 対象：ピットアウト時刻が記録され、その直前に対応するピットインラップが存在するピットストップ。
- 形式：列をドライバーとする表。各セルには、ピットアウトラップ番号、ピットレーン入口からコントロールラインまでの時間 [s]、コントロールラインからピットレーン出口までの時間 [s]、両者の合計 [s]、ピットインラップとピットアウトラップのラップタイム [s]、その2周の合計時間 [s] を表示する。
- 集計：最終列にピットストップ件数と、ピット所要時間の平均・最小・最大 [s] を表示する。

## 4. スタート分析

HTMLセクション：`#start-analysis`

### [R-10] スタート後10秒間の速度推移

- 対象：各ドライバーの実際のレーススタートから10秒間の速度テレメトリー。
- 形式：画像として埋め込む、ドライバー別の系列を持つXYプロット。X軸はレーススタートからの経過時間 [s]、Y軸は速度 [km/h]。

### [R-11] スタートから第1コーナーまでの速度推移

- 対象：各ドライバーの実際のレーススタートから第1コーナーまでの速度テレメトリー。
- 形式：画像として埋め込む、ドライバー別の系列を持つXYプロット。X軸は各ドライバーのスタート地点からの走行距離 [m]、Y軸は速度 [km/h]。第1コーナーの位置を縦線で表示する。

## 5. タイヤ

HTMLセクション：`#tyres`

### [R-12] レース中のタイヤ使用履歴

- 対象：各ドライバーのレース全体のタイヤ使用履歴。
- 形式：画像として埋め込む表形式のグラフ。X軸はラップ番号 [lap]、Y軸はドライバー番号。ドライバーは走行周回数が多い順とし、同数の場合は完走順位順とする。
- 表示内容：各周回をコンパウンドの色で塗り、セル内にタイヤ使用周回数 [laps] を表示する。スティントの開始セルには新品を `N`、ユーズドを `U` と記載し、同一コンパウンドへの交換を含むスティント境界を縦線で示す。

### [R-13] 週末全体の新品タイヤ投入履歴

- 対象：各ドライバーの当該グランプリにおける、全セッションを通した新品タイヤの投入履歴。
- 形式：列をドライバーとする表。上段にはコンパウンド別の投入セット数と括弧内の割当セット数、下段には投入順にセッション名を表示し、セルの色でコンパウンドを区別する。全コンパウンドの合計欄はない。

## 6. 気象

HTMLセクション：`#weather`

### [R-14] 気温の推移

- 対象：レース中の気象観測履歴。ドライバー別ではなくセッション共通。
- 形式：画像として埋め込むXYプロット。X軸は観測時刻 [UTC, HH:MM]、Y軸は気温 [°C]。

### [R-15] 降雨の有無の推移

- 対象：レース中の気象観測履歴。ドライバー別ではなくセッション共通。
- 形式：画像として埋め込むXYプロット。X軸は観測時刻 [UTC, HH:MM]、Y軸は降雨の有無（0：降雨なし、1：降雨あり）。

### [R-16] 路面温度の推移

- 対象：レース中の気象観測履歴。ドライバー別ではなくセッション共通。
- 形式：画像として埋め込むXYプロット。X軸は観測時刻 [UTC, HH:MM]、Y軸は路面温度 [°C]。

### [R-17] 風速の推移

- 対象：レース中の気象観測履歴。ドライバー別ではなくセッション共通。
- 形式：画像として埋め込むXYプロット。X軸は観測時刻 [UTC, HH:MM]、Y軸は風速 [m/s]。
